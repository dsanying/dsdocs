## Edit documents

Run `pnpm studio` at the project root and open `http://localhost:5180`. Use the file tree to create pages and folders or change their order. Edits automatically save to MDX files.

<Callout type="info" title="Saving is separate from publishing">
  Saving updates the working directory. Readers see changes only after you run `pnpm build` and
  deploy the output. Keep unfinished documents outside the published content directory.
</Callout>

## Organize directories

Use actual folders and their `meta.json` files to control titles and ordering. Studio manages the official metadata; the reader uses the native Fumadocs page tree.

## Maintain translations

Keep matching relative paths under `zh` and `en`, such as `zh/getting-started.mdx` and `en/getting-started.mdx`. The reader language menu links the translations. Studio edits the two files separately and does not provide a side-by-side translation dashboard.

## Publish

Run `pnpm check` to validate and build, then `pnpm preview` to inspect the static site under `/docs`. Production needs only `apps/reader/out`, with no Studio or database dependency.

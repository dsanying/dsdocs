## Create a document

Create a document in the administration panel, enter its title, path and source, then save it. Saving creates a draft. Readers see the content only after you publish it.

<Callout type="info" title="Drafts and publishing are separate">
Editing a published document leaves its previous public version available. Preview your changes, then publish the new revision.
</Callout>

## Organize directories

Use `/` between directory levels. A directory such as `Product/API` creates two expandable levels. The order field controls page ordering.

## Maintain translations

Create another language from the document details. Translations share a stable association but are saved and published independently.

## 编辑文档

在项目根目录运行 `pnpm studio`，打开 `http://localhost:5180`。左侧文件树可以创建页面和目录、调整顺序；选择页面后直接编辑，修改会自动保存到 MDX 文件。

<Callout type="info" title="保存不等于发布">
  保存只更新工作目录。执行 `pnpm build`
  并部署新产物后，读者才会看到更新。正在编写的文件不要提前放进需要发布的内容目录。
</Callout>

## 组织目录

使用真实文件夹组织目录，使用每个文件夹内的 `meta.json` 控制标题与顺序。Studio 的文件树维护这些官方元数据，读者端直接使用 Fumadocs 目录树。

## 维护翻译

中文页面放在 `zh`，英文页面放在 `en`。对应页面保持相同的相对路径，例如 `zh/getting-started.mdx` 与 `en/getting-started.mdx`，读者端的语言菜单会跳转到对应译文。Studio 中分别编辑两份文件，没有并排翻译管理面板。

## 发布

运行 `pnpm check` 验证并构建，随后运行 `pnpm preview` 检查 `/docs` 下的静态站点。生产部署只需要 `apps/reader/out`，不依赖 Studio 或数据库。

这是一篇可以直接在管理后台打开的格式示例。读者端展示渲染结果，编辑器的源码模式展示 Markdown 写法。你可以修改草稿练习，点击发布后再看读者页面的变化。

:::note
本页覆盖 DSdocs 当前支持的常用格式，不代表任意 Markdown 扩展都可使用。标题和路径在文档信息中填写，不需要在正文写 front matter。
:::

## 标题与目录

正文通常从二级标题开始，依次使用三级、四级标题组织内容。读者端会自动生成本页目录和标题锚点。

### 三级标题

用于一个主题中的子问题。

#### 四级标题

用于确实需要进一步展开的说明，尽量避免过深的标题层级。

## 文字与段落

这是普通段落。**粗体**用于强调关键词，*斜体*用于轻量强调，~~删除线~~可以表示已取消的做法。`DSDOCS_DATA_DIR` 是行内代码。

段落之间空一行。需要显示 Markdown 符号本身时可以转义，例如 \*这不是斜体\*。

> 引用用于摘录或补充说明。
>
> 引用中也可以有 **强调**、`行内代码` 和多个段落。

---

上面的横线用于分隔内容。实际文档通常优先用标题组织结构，不必频繁加入横线。

## 列表与步骤

无序列表适合并列的信息：

- 目录组织主题。
- 页面回答具体问题。
  - 标题解释子问题。
  - 段落给出必要细节。

有序列表适合操作步骤：

1. 新建文档。
2. 编写正文并等待保存。
3. 点击发布，查看读者页面。

任务列表适合展示检查项：

- [x] 写好标题和简介。
- [x] 检查链接和代码示例。
- [ ] 按自己的需要修改这篇示例。

读者端的任务列表用于展示，修改勾选状态需要在编辑器中操作并发布。

## 表格

| 内容   | 用途             | 示例                |
| ------ | ---------------- | ------------------- |
| 标题   | 组织章节         | 快速开始            |
| 提示框 | 突出补充说明     | 保存只更新草稿      |
| 代码块 | 展示可复制的代码 | JSON、Shell、Python |

表格适合简短的对照信息。长篇说明应放在段落中，避免在窄屏上堆出过宽的表格。

## 提示框

:::note
**说明**：介绍阅读当前内容所需的背景。
:::

:::info
**信息**：自动保存为草稿，发布后才对读者可见。
:::

:::tip
**建议**：写完后切换到读者页，检查链接、图片和代码。
:::

:::caution
**注意**：重新加载可能丢弃当前未保存的内容，先保留自己的改动。
:::

:::danger
**重要操作**：删除文档会同时删除其发布历史，确认不再需要后再操作。
:::

提示框写法如下；指令名可以替换为 `note`、`info`、`tip`、`caution` 或 `danger`：

```text
:::tip
这里填写提示内容，可以包含 **粗体** 和列表。
:::
```

## 代码块

代码块保留换行和缩进，读者可以点击复制按钮。围栏后写语言名称，便于语法高亮；代码只是展示，不会执行。

### Shell

```bash
pnpm install:all
pnpm build
pnpm manage
```

### JSON

```json
{
  "project": "DSdocs",
  "languages": ["zh", "en"],
  "publishAfterSaving": true
}
```

### Python

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("DSdocs"))
```

### TypeScript

```ts
type DocumentStatus = 'draft' | 'published';

const document: { title: string; status: DocumentStatus } = {
  title: '开始使用',
  status: 'draft',
};
```

### 纯文本

```text
使用有序列表描述步骤。
使用代码围栏展示配置和命令。
正文不执行 HTML、JavaScript 或任意 React 组件。
```

## 支持范围

当前支持普通 Markdown、GFM 表格和任务列表，以及本页展示的五种提示框。代码语言无法识别时会按纯文本保留内容。

标签页、数学公式、脚注、Mermaid 图表、任意 HTML、MDX 的 import 和可执行组件不属于当前首版支持范围。需要展示这些语法本身时，放进代码块即可。

## 整理目录与页面

在「目录」中新建目录，填写中文名称和英文名称。可以选择父目录形成层级；不需要为了区分主题再创建一套独立手册。

在文档的「所属目录」中调整归属。目录名称修改后会更新读者导航；文档的标题、路径、简介、归属和正文需要发布后才替换读者看到的版本。含有文档或子目录的目录不能直接删除。

:::tip
目录用于组织主题，页面内的标题用于组织内容。一个主题只有几段说明时，合并为同页的小节通常更容易阅读。
:::

## 编辑与自动保存

可视化模式适合日常写作：选择标题层级，插入列表、表格、链接、图片、提示框和代码块。点击编辑器的源码模式按钮，可以直接修改 Markdown；切回可视化模式后检查排版。

留意保存状态：

| 状态           | 应当怎样处理                                   |
| -------------- | ---------------------------------------------- |
| 待保存、保存中 | 保持页面打开，等待完成                         |
| 已保存         | 草稿已写入数据库，可以继续编辑或发布           |
| 保存失败       | 查看错误，重试保存；重新加载前先保留自己的改动 |

同一文档被其他窗口修改时，系统会拒绝用旧版本覆盖新版本。不要直接反复发布；先保留自己的文字，再重新加载并合并改动。

## 发布、撤下与历史版本

- **发布**：检查并公开当前草稿。格式或附件引用有问题时，旧的已发布版本仍然保留。
- **撤下**：从读者端移除页面，保留草稿和发布历史。
- **历史版本**：把某次发布内容恢复为草稿。恢复后仍需点击发布，才会替换读者内容。
- **删除**：删除文档及其历史版本。只想暂时隐藏时，使用撤下即可。

## 图片和附件

插入图片时可以上传文件；「插入附件」会上传文件并在正文中加入下载链接。「附件」页面可以集中上传和删除资源。

支持 PNG、JPEG、WebP 图片、PDF 和纯文本，单个文件不能超过 5 MiB。文件只有被已发布正文引用时，才可从读者端访问。

:::caution
被草稿或已发布文档引用的附件不能删除。先移除正文中的引用并发布，再到附件页删除。发布历史中的旧引用不会单独阻止删除，因此恢复旧版本后需要检查附件是否仍然存在。
:::

## 关联中英文文档

1. 先创建一个语言的文档。
2. 新建另一语言的文档，选择对应语言，并在「关联翻译」中选择前一篇文档。
3. 分别编写和发布两个语言版本。
4. 在读者页切换语言，确认进入同一主题的对应页面。

两个语言版本独立编辑、独立发布，系统不会自动翻译正文。读者首次进入时按浏览器语言选择；手动切换后，会记住选择。初始教程已经成对关联，可以直接体验。

## 账号与权限

超级管理员可以创建和管理普通管理员，不能删除或降级超级管理员账号。普通管理员只能看到自己的账号，可以核验当前密码后修改自己的用户名和密码。

两种身份编辑文档的权限相同。账号信息修改后需要重新登录。密码只保存哈希，后台不能查看原密码；忘记密码时，由超级管理员重置普通管理员的密码。

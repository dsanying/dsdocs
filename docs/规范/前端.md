# 前端规范

读者端采用原生 Fumadocs 布局、组件、主题、目录树、搜索和语言菜单，不维护上游分叉。原版编辑端直接运行官方 Studio；统一面板通过公开接口组合官方文件树和可视化编辑器，不重写它们。账号页仅调用身份 API 薄适配。

展示品牌使用 DSdocs，技术标识使用 dsdocs。仅对语言偏好、子路径和 Studio 附件路径添加必要适配。新增适配必须验证中英文、亮暗主题、宽窄屏与键盘交互，不覆盖上游样式。

官方 Studio 的上游品牌、英文界面和原生控件保持原样。不能为统一品牌而篡改第三方许可、依赖名称或上游界面。项目自身的标题和说明使用 DSdocs。

可视化与源码模式的语法范围以实际上游行为为准，不承诺任意 MDX 均可视化。浏览器验证须检查保存后的实际文件与重新构建的读者显示。

统一面板采用 Fumadocs Editor 原生兼容模式，保留上游 Provider、主题、样式和保存机制，不引入 Ant Design 包装器或声称完整复刻。DSdocs 外层提供中文导航、主题切换、账号表格和表单，操作反馈在右上角，加载失败就地重试。账号列表按用户名排序后筛选、分页，默认每页 10 条。账号页使用成熟身份服务；authentik 原生支持简体中文，默认品牌配置 zh-Hans。文档编辑器按用户确认保留官方英文控件，不修改依赖进行汉化。

只在独立浏览器上下文测试，不复用用户的日常会话。截图、日志不得包含密码或会话令牌；不要对已填写密码的表单输出完整可访问性树。

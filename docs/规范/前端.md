# 前端规范

读者端采用原生 Fumadocs 布局、组件、主题、目录树、搜索和语言菜单，不维护上游分叉。编辑端直接运行官方 Studio，禁止另做一套文件树、可视化编辑器或页面管理表单。

展示品牌使用 DSdocs，技术标识使用 dsdocs。仅对语言偏好、子路径和 Studio 附件路径添加必要适配。新增适配必须验证中英文、亮暗主题、宽窄屏与键盘交互，不覆盖上游样式。

官方 Studio 的上游品牌、英文界面和原生控件保持原样。不能为统一品牌而篡改第三方许可、依赖名称或上游界面。项目自身的标题和说明使用 DSdocs。

可视化与源码模式的语法范围以实际上游行为为准，不承诺任意 MDX 均可视化。浏览器验证须检查保存后的实际文件与重新构建的读者显示。

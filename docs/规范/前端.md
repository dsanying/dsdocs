# 前端规范

管理端采用原生 Ant Design 组件。公共页面容器、表格、错误反馈、操作按钮与数据读取集中在 `apps/admin/src/ui.tsx`；主题和语言分别由 `settings.tsx`、`i18n.tsx` 管理。业务页面不复制另一套基础组件。

唯一项目品牌为 dsdocs。路由、类型、文件、变量和 UI 标签采用通用文档管理概念，不包含部署单位、其他产品的业务名或来源项目路径。依赖名称只用于实际技术说明、导入和许可声明。

正文和控件使用 14px 基准字号、32px 默认控件高度。主题从唯一配置派生，亮暗模式保持状态语义；启动和成功使用成功色，删除和下线使用危险色，普通主操作使用品牌蓝。页面 CSS 只负责布局和正文适配，不覆盖 Fumadocs 读者端样式。

页面按列表、详情、编辑组织。详情字段完整展示并可自然折行；表格长值在独立单行区域滚动。表头和正文左对齐，数字使用等宽字形。实体先对完整集合排序再分页，默认每页 10 条，候选 10/20/50/100，操作列固定在右侧。

字段说明放在字段标题旁的 tooltip，不用占位符代替说明。只读字段使用可阅读的文本。可视化编辑使用官方编辑器，同时保留 MDX 源码入口，保存和预览从编辑器即时读取完整源码，避免防抖期间丢失最后一次输入。

保存、取消仅在存在修改时出现；保存中禁止重复写入。取消不提交内容，离开未保存页面时提示。读取错误在原位置提供重试，写操作反馈由 Ant Design App 的右上角通知提供，不重复插入结果 Alert。

新增文案同时提供中文和英文，不以缺失键回退掩盖遗漏。图标按钮必须有可访问名称。界面验收覆盖中英文、亮暗主题、宽窄屏、键盘操作及真实业务请求。官方编辑器的上游界面保持原生，不承诺其全部文案已汉化。

读者端只使用 Fumadocs 原生布局和公开配置。子路径、语言、内容源和组件绑定在适配层处理，不修改上游包源码。

# 前端架构与设计规范

本章组适用于 React + Ant Design 完整复刻入口。仓库已有的其他组件体系（如 Fumadocs、Django/Unfold）保留原生机制，按各自规范做局部适配或保持现状；在本仓前端规范入口明确各入口适用范围，不跨体系强制同名组件或 Ant 门禁。

本项目前端架构、设计、组件、文案和验证的唯一规范正文，适用于全部现有与新增页面。规则与代码、验证的对应关系登记在 [manifest.json](../manifest.json)，维护入口见 [维护手册](../../维护手册.md)。

门禁报错里的 `FRONTEND-*` 就是下表的规则 ID：按 ID 找到对应章节即可看到完整条文与原因。

## 来源、目标与边界

本规范与随仓公共实现（公共组件入口、`--ds-*` 设计变量、门禁脚本）提炼自多个生产管理前端的共同实践，是本仓界面的唯一契约，由本仓库独立维护；不在本仓源码内的参考实现不是本项目已实现事实。

本项目是克制、清晰、高密度的管理控制面：业务事实、状态和操作优先，装饰退后。继续使用 React、Ant Design 与现有 API 契约（本基线不使用 Ant Design Pro，门禁禁止引入）；样式统一采用同目录普通 CSS 与 `--ds-*` 设计变量，不使用 CSS-in-JS（本基线不使用 `antd-style`，门禁禁止引入）。新机制必须减少分叉，不能以迁移别名、页面例外或第二套基础组件长期共存。

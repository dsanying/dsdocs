# 布局与响应式

排版、断点、滚动所有权与内容放不下时的取舍。规范总览与阅读顺序见 [README](README.md)。

## FRONTEND-LAYOUT：排版、响应式与滚动所有权

- 应用壳只保留产品名、主导航、语言、主题切换和账户。`AppPage` 提供唯一语义一级标题、主要操作与页面留白；字符串或 ReactNode 标题都由共享层生成同一标题结构，不把原生 `title` 当作全文入口，正文不得重复页头。页签已是该区域标题时，面板内不再放同名区块标题（`SectionHeader`、`TablePanel`/卡片 `title`），原挂在标题行的对象操作（新建等）移到表格上方工具栏（`Table`/`DataTable` 的 `toolbar`）。页签按作用域落位：决定整张卡片/表格内容的页签放进所属卡片内（`ResponsiveTabs` 与内容同卡，内层面板用 `embedded`）；决定整页多区块内容的视图切换使用 `ResponsiveTabs` 导航页签（line 原生形态），不再套卡也不另配区块标题；业务实体详情页的页签由 `EntityDetailPage` 给出（页头 `tabList`）。页面、区块、标题操作行分别使用 `PageStack`、`ContentStack`、`SectionHeader`，相邻间距只由父布局管理；不得用负 margin 抵消组件留白。gap 容器直接子级自带的尾部外边距统一归零（`layout.css` 覆盖 stack 子级、`AppPage.css` 覆盖页级页签；页签 header、查询条的 `margin-block-end` 只在没有父级 gap 的卡片/弹层体内生效）。页头簇 `ds-app-page__header`（面包屑/标题行/说明区/页级页签）内间距统一取 block 角色。`expectConsistentStackSpacing` 实测 stack、页面根 `ds-app-page`、页头簇与详情说明区 `ds-entity-info` 相邻子项的盒间距与父级 gap 相等，外边距穿透或非标间距直接拒绝。
- **详情页的字段只在页头出现一次**：页头信息网格（`InformationFieldGrid compact`）以标签在上、值在下的紧凑布局覆盖编辑表单里的可编辑业务配置（新增表单字段时同步只读展示）和有业务用途的只读元数据（创建/重置/评估时间等）；纯路由、内部生成 ID 默认隐藏，有业务查询或排障用途的标识保留。已有真实客户端预览时复用其渲染，再补必要的只读配置核对，tab 正文不再另设"详细信息"卡片重复其中任何字段；用结构化视图已经表达的内容（如用户规则由"关联用户"表呈现、过滤条件组由 `FilterRules` 只读视图呈现）不再裸露 JSON。
- **字典/清单类数据用平铺表格，不用"树 + 详情"两步查看**：字典类清单（每条记录只有几个字段），一张 `TablePanel` 表格把全部字段列出、编辑/删除放行内、关键词过滤 + 高亮即可；**"同一份数据的不同视角"用列而不是用切换**："直接 / 继承 / 最终结果"这类多视角数据一律做成同一张表的并列列（直接授权列可编辑、继承列带来源、最终结果列汇总），不再用"范围"切换让用户来回翻；树/表格双视图也不再提供——树形只在需要按层级批量操作时才引入。深链聚焦某条记录时用关键词把表格定位到该行。**多对多绑定（主体 ↔ 标签这类"已绑定 + 可添加"）只用一个 `MultiSelect` 承载**：已绑定的是已选值、可添加的是候选，删除 = 移除标签、添加 = 选中候选，不再拆成"已有 / 可添加"两栏卡片列表；**间接得到的（继承）绑定只读展示在控件下方并按来源分组**（"来自规则 X 的继承标签：" + 标签块），与可编辑的直接绑定分开，来源由后端 `inheritedGroups[].via` 给出。
- **间隔只有四档角色，且只由容器 gap 表达**：页面级区块之间 `page`（`--ds-space-24`）、区块内子块之间 `block`（16）、控件/字段之间 `control`（8）、标签与其值等紧贴关系 `tight`（4）。业务层用共享 `PageStack`/`ContentStack`/`Stack gap="page|block|control|tight"`（`direction="row"`、`wrap`、`align`、`justify` 覆盖横排场景）、`ResponsiveActions`、`Space size={designTokens.space.sm|lg}`、`Row gutter` 承载间距；`Stack` 本身零内边距、零边框，只负责子项排列。业务代码（`src/components/ui/` 之外的 TSX 与 CSS）禁止用任何非零 `margin*` 制造间隔（清零 `0`/`auto` 允许），也禁止把 `gap`/`Space.size`/`Row.gutter`/`Flex.gap` 取到四档之外的 token（`space.md/xxs/xxl/xxxl`、`--ds-space-2/12/32/40` 只留给共享组件内部的内边距与细节对齐），静态门禁强制；圆角、边框与字号同理只取 `--ds-radius-*`/`--ds-color-border*`/`--ds-font-*` 标度（FRONTEND-THEME）。共享层例外仅限：ui 层组件内部实现、`.ds-prose` 正文排版（段落/标题/列表的行文间距属于阅读节奏，由 `prose.css` 一处定义），以及第三方注入的 `hljs-*` 类。
- **视口壳与分区滚动**：管理工作台使用 `ViewportFrame` 约束视口高度；侧栏使用 `SidebarFrame`，品牌固定在上区，菜单只在中区按需纵滚，账号、主题与语言固定在侧栏底部，不随菜单内容结束位置排列。短视口下菜单收缩并滚动，底部控件超出可用空间时只滚动该区。主内容与目录、编辑正文分别分配滚动所有权，完整 flex/grid 高度链须有 `min-height: 0` 和可收缩宽度；不得依赖全页 body 纵滚，也不得仅隐藏根滚动条来裁掉内容。普通管理页由主内容区滚动；文档/工作台的固定标题和主要操作留在上方，长正文使用有可访问名称的 `ScrollRegion`。窄屏或高度不足时可让当前工作区内部整体滚动，保证所有字段、操作和正文可达，但不得带动应用导航或页面根。原生兼容读者页、营销页和长篇阅读页仍按其框架原机制滚动，不强制套用管理壳。浏览器在亮暗主题、320/768/1440px、短视口、长菜单和长正文中，以真实滚轮正反向和到边界继续滚动验证独立性、账号区位置与根页面不溢出；`viewport-contract` 必须拒绝失去高度约束的反例。
- **侧栏折叠只剩图标，折叠入口在顶部**：桌面侧栏的展开 / 收起按钮与品牌同一行放在顶部（`Sider trigger={null}`，不用 Ant 默认的底部触发条）；折叠后品牌只剩图标，这个图标本身就是展开按钮（悬停 / 聚焦换成展开图标），菜单只剩图标，底部用户、主题、语言竖排只剩图标，被隐藏的用户名与语言名由全局 `IconLabelHint` 在悬停 / 聚焦时显示（非按钮元素标 `data-icon-only`，文字放 `.ds-visually-hidden`）；任何一项都不得越出侧栏。折叠状态记在 localStorage（每位使用者自己的偏好，读写失败按展开处理）。窄屏侧栏收进抽屉，不受折叠影响。
- **卡片与图表并排只用共享 `ResponsiveGrid`，列数由自身可用宽度决定**：侧栏展开、弹窗、分栏里内容区的宽度与视口无关，按视口断点分列（`Col xs/sm/lg`）会在窄内容区里硬塞多列，把卡片内的数字与迷你图挤出边界。`ResponsiveGrid` 以容器查询按版式与子项数选择能均衡分行的列数（`cards` 最小 280px：3 项 1/3 列、4 项 1/2/4 列；`charts` 最小 400px；`wide-narrow`/`narrow-wide` 两项 2:1；`split` 两栏等宽每栏最小 420px 且顶端对齐），放不下时整体降为单列，不出现孤儿行与大片空白；`SummaryStrip` 按下一条“多个一行”的判定由内容宽度选列、每行首格不画分隔线。子项直接放卡片，不再包 `Col`。容器查询（`@container`）只写在共享层 `components/ui`，业务样式不得自定阈值；卡片内部的横竖切换用 `flex-wrap` 让次要块整块换行（如 KPI 迷你图放不下时整行落到数字下方），不得把内容挤出卡片。静态门禁拒绝 `Col` 响应式列直接包 `Card`/`*Card`，以及业务样式中的 `@container`。
- **表单字段并排只用共享 `FormGrid`，列数由表单自身宽度决定**：编辑表单常放在“表单 + 预览”分栏、抽屉和弹窗里，按视口断点手排 `Row`/`Col` 会在窄表单里挤成一列或在宽表单里一行只放两项。`FormGrid` 默认以容器查询排 3 / 2 / 1 列，各行同一列宽对齐；Cron 这类固定五项短字段组合使用 `columns={5} field="short"`，宿主至少 632px 时五项一行，不足时沿共享短字段规则降为三 / 二 / 一列；`field="short"`（数字 + 单位、开关、候选很短的下拉，最小 120px）与默认 `medium`（日期时间、短文本，最小 200px）决定同样宽度下能放几列，中英文标题、名称 + 说明这类中等长度文本传 `columns={2}`；列表编辑器里“短标识 + 两个短字段”（通知操作按钮：类型标签 + 中文 + 英文）用 `lead`：标识按自身宽度（保底 100px 让各行对齐）、其余两项均分，三项一行；不可变的属性（按钮类型——规则按钮由页面规则生成、链接永远是链接）只读展示成标签，不给可选的下拉，也不另写“仅支持修改文案”之类说明；条件组、富文本、列表编辑器等宽字段放在网格外独占一行。只在某些组合下才生效的字段（如通知倒计时只对“右下角弹窗未强制阅读”与“全屏遮罩强制阅读”有意义）按组合显示、标签与说明随含义切换，不生效时隐藏但保留值。静态门禁拒绝 `Col` 里的 `Form.Item`。
- **“多个一行”怎么算合理（三类并列，各一条规则）**：
  1. **指标/摘要并列（`SummaryStrip`，项数固定且少）**：列宽取各项内容不折行时的固有宽度中最宽者，各列等宽；列数取同时满足“放得下（n × 列宽 + 间距 ≤ 容器宽度）”与“分行均衡（整除项数，或 3 列以上末行只空一格，如 5 项 3+2；2 列时不允许 2+1）”的最大 n。**放得下就多列，不得用固定最小宽度阈值让短值（如 `1`、`0`、`关系正常`）各占一行。** 算法唯一实现是 `components/ui/balancedColumns.ts`，运行时门禁 `expectEfficientSummaryStrips` 在真实页面按同一算法核对实际列数，`expectBalancedGrids` 拒绝孤儿行。
  2. **卡片/图表并排（`ResponsiveGrid`）**：内容需要最小可读宽度（迷你图、坐标轴），按版式最小宽度（`cards` 280px、`charts` 400px 等）与上条同一均衡规则选列，不用内容固有宽度。
  3. **同质列表（标签、候选项等可变数量的条目）**：每项至少 280px、按可用宽度 `auto-fill` 等宽多列，**按全局分页标准分页（默认每页 10 项，与表格同一 `buildTablePagination`）**，末页末行允许不满；不得一次性平铺全部条目把下文推出视野。键值信息（`InformationFieldGrid`）按容器宽度以 240px 为单格预算、最多四列，空间不足依次降为三/二/一列；在这一上限内再按短字段数量选分行均衡的列数（最大列数整除或末行只空一格时直接采用，否则少一列能整除就少一列，再否则取末行至少半满的最大列数；如 15 项为 4+4+4+3、5 项为 3+2、6 项为 3+3，不出现 4+1），末行空出的格均分给末行字段，不让单个短字段独占整行。所有详情网格（含页头紧凑网格）的标签都在上、值在下，避免标签与值左右并排时在窄格里把邮箱、账号等值拆成两行；普通标题及中英文字段不因语言或长度固定占整行；短字段按阅读顺序连续排布，`span="full"` 字段由共享组件统一排在短字段之后，不得把短字段切成多个半空行，也不用人为 `row` 分组；正文、复杂规则或确实需要大空间的集合才使用字段 `span="full"` 独占整行（标签绑定这类通常很短的集合不占整行），标签、值、标识符与集合完整自然折行，超长连续内容用 anywhere 断行；详情信息区不省略、不横滚、不折叠，复用的单行组件在此上下文同样展开。普通数据列表继续使用既有滚动契约。`expectReadableInformationFields` 在共享夹具和真实页面验证标签位置、值宽度及整行字段，分组回归验证宽屏等宽并排和窄屏降列。
- 页面最小支持宽度为 320px，验证断点为 320/768/1440px。Grid/Flex 子项必须可收缩并自然换行；工具栏和表单窄屏单列，主要操作保持可见。CSS/容器能力优先；只有图表等组件 API 必须改变行为时才用统一 breakpoint hook。
- **禁止词项被迫折行**：名称、状态、指标标题与数值、按钮文案、页签/切换项、表单标签、区块标题、面包屑、菜单项、**表格列标题**都是“单个词项”（≤16 字），只能整体占一行（列标题由共享 `Table` 按标题文字量出下限抬高列宽——`tableConfig.titleFitWidth`，表头 `white-space: nowrap`，业务不必为标题长度改列宽标度）；空间不足时由父布局降列（响应式 `Col xs/sm/md`、`StatisticSummaryGrid` auto-fit、`InformationFieldGrid` 单列、`ResponsiveActions` 换行）或隐藏次要项（窄屏头部只留头像），绝不允许在词内折行、把 svg 图标挤扁或让固定宽度槽位（如页头 `extraContent`、写死 `width`）把值挤成多行；超过 16 字的句子才允许自然换行。`InformationFieldGrid` 详情上下文例外：标签、值及状态按上一条完整展开规则自然折行，不受词项单行约束。共享 `StatisticSummaryGrid`/`StatusTag`/品牌区已内置 `nowrap`；业务层 `Col` 固定 `span`（无 `xs/sm/md/lg/flex`）被静态门禁拒绝；UI 测试 `expectNoForcedWraps` 在 320/768/1440 真实页面上按词项选择器（`tests/ui/forced-wrap.ts`）用 Range 行盒检测折行并列出元素与文案，任一命中即失败。
- **复合面板是一块表面切割而成，不是多个方块拼出来的**：字段网格、分组表头、工具栏容器这类“一个大板块内有若干小格”的结构，由唯一的外层容器提供圆角与 1px 外框，内部用 `overflow: clip` 裁切、以 `gap: var(--ant-line-width)` 露出与外框同线宽的分隔线来切格；内部单元不得各自带边框、圆角或更粗的缝隙，让圆角外框与直角方块看起来是两套东西。分组表头、工具栏容器沿用切割模式；**键值字段网格不是切割面板**——`InformationFieldGrid` 在同一表面上只靠留白分格（内部无框线，读作“一组字段”而不是“一张数据表”），是该模式的唯一实现，页面不得自绘键值网格。实体详情页头的说明区（`EntityDetailPage`：摘要条 + 字段网格）合并为同一张表面 `ds-entity-info`，两区块间一条分隔线，并入的字段网格去掉自有外框。卡片正文只有一个键值网格时，卡片本身仍按贴边处理：`Card styles={{ body: { padding: 0 } }}` + `InformationFieldGrid flush`，网格贴边接在卡片头分隔线之下、只保留卡片底部圆角（无外框留白分格），标题下不得留一圈空白再摆一块直角网格（静态门禁强制 flush 的宿主与唯一子元素条件）；与其他内容并列时使用默认圆角面板。CSS 门禁对“边框色做底 + gap 分隔 + 圆角”的规则强制 `overflow: clip` 与 1px gap。
- **区块卡片头部统一**：带标题/操作的区块卡片只用 Ant `Card`（`title`/`extra`），标题下固定 1px `--ds-color-border` 分隔线；无标题容器直接用不带 `title` 的 `Card`。任何贴边填充卡片正文的内容（flush 网格、表格）都必须保留这条分隔线，不得用正文覆盖，全项目所有卡片标题下的横线有无与线宽一致。
- **禁止框套框**：一个视觉层级只允许一层边框/表面。卡片（Ant `Card`）内不得再放卡片——内层区块用 `SectionHeader`（`headingLevel` 3+）+ `ContentStack` 分组、指标用 `StatisticSummaryGrid`、状态高亮用语义 `Alert`，层级差异靠弱表面底色与圆角而非再加边框；自带轨道外框的 `ViewSwitch` 不得再套 `Card`（横向页签是 line 原生形态、没有外框，按作用域落位条款直接放进所属表面）、`Row/Col` 仅作为容器的壳也不例外。浮层（Modal/Drawer/Popover）是新表面，其中的卡片不计入嵌套。静态门禁强制。
- document 是页面纵向滚动唯一所有者，页面根不得隐藏、裁切或接管横向滚动。一个区域同一轴只能有一个滚动所有者；Modal/Drawer 内容、虚拟树、编辑器、iframe 与图表外壳不得和内部内容形成同轴双滚动。
- 宽表、代码、日志、规则预览和时间轴保持二维关系，使用 Table 滚动配置或带可访问名称的 `ScrollRegion` 在自身边界滚动。Tabs/ViewSwitch 只滚动自身导航；聊天只让消息区纵滚，代码和表格在消息内横滚。
- 使用动态视口高度 `dvh`，不用会被移动浏览器工具栏遮挡的 `vh`。固定宽度控件必须通过共享响应式尺寸收口；不得使用 `100vw`、负外边距、绝对定位或整组横滚补救布局。

### 内容放不下时的决策

| 内容 | 统一处理 | 禁止做法 |
| --- | --- | --- |
| 正文、错误、风险 | 自然换行并增高 | 省略、固定高度裁切、藏进 Tooltip |
| 标题、状态、按钮、字段标签 | 给足空间或整行换行 | 缩字号、无全文入口省略、隐藏主要操作 |
| 标识符、哈希、ID、路径、单个长值 | 用 `AtomicValue` 单行显示全文，放不下在自身范围内左右滚动；需要复用的加 `copyable` | 固定字符切片、省略号、原生 `title`、悬停 Tooltip 看全文 |
| Tabs、ViewSwitch | 标签完整，由组件自身横向浏览 | 截断标签、撑开页面根 |
| 工具栏、筛选、表单、操作组 | 自然换行，窄屏字段满宽 | 整组横滚、固定宽度挤出视口 |
| 宽表、代码、日志、时间轴 | 局部横向浏览，保留关系 | 页面横滚、强制单元格全部折行 |
| 单对象字段 | `InformationFieldGrid` 响应式降列 | 为避免降列改成横滚表 |
| 图表 | 容器重排、调整刻度，必要时独立展开 | 裁切图例、极小字号、页面横滚 |

选择顺序固定为：删除非必要信息，允许换行或降列，为必须保持关系的区域提供局部滚动，最后让单个过长值在自身范围内左右滚动（不省略）。

# 架构、主题与样式

目录与依赖边界、唯一主题与设计标度、唯一样式方案。规范总览与阅读顺序见 [README](README.md)。

## FRONTEND-ARCHITECTURE：目录、依赖与开发边界

- `routes/` 只定义路由与代码分割，`layouts/` 只负责应用壳；`pages/<Page>/` 组合页面及本页组件；跨页面业务组件放 `components/`；基础视觉与交互契约只从 `components/ui` 公开入口导入；请求和状态分别归 `services/`、`hooks/` 或 `stores/`。禁止 `pages/components`、页面间互相导入实现和无真实复用方的全局抽象。
- 页面目录与入口使用 `PascalCasePage/index.tsx`，React 组件及其文件使用 PascalCase，Hook 使用 `useXxx`，service 使用业务资源名并只承载传输契约，纯工具使用动词或领域名，类型以业务概念命名而不追加含糊的 `Data`/`Info`。同页私有组件放 `pages/<Page>/components`；**页面 `index.tsx` 只负责组合**：表格列定义放同页 `columns.tsx`（导出 `buildXxxColumns(options)`，事件与外部数据经参数传入），表单值与请求体的转换放 `xxxModel.ts`，抽屉/弹窗的打开状态与提交放 `useXxxEditor.ts`——静态门禁拒绝在 `pages/**/index.tsx` 里出现 `TableColumnsType`/`ColumnsType`；只有至少两个真实页面以相同语义复用时才提升到 `components/`，与业务无关且统一视觉或交互契约的能力才进入 `components/ui`。
- 统一函数与统一组件同等约束：同形工具逻辑（文件下载、剪贴板复制、日期与数字格式化等）在 `src/utils/` 与 `src/hooks/` 只允许一个实现，页面不得各自内联同形副本；已收口的入口是 `downloadBlob`、`copyTextToClipboard`、`formatDateTime/formatDateTimeMinute/formatDate/formatMonthDay/formatDateLabel`、`formatCompactNumber`、CSV 的 `csvExport` 与 Cron 的 `cronCycle`。发现第二个同形实现时应并入统一入口而不是并存。
- 拆分以职责、状态所有权和复用边界为准：路由入口负责组合，数据 Hook 负责请求状态机，展示组件接收明确数据与回调，service 不持有界面状态。一个文件同时承担请求、复杂状态编排和多个独立展示区时应按这些边界拆分；仅因行数长、仅被一处调用或为了绕过检查不得抽象。超大文件只作为人工评审候选，不设纯行数硬门禁。
- 页面按 AppPage 页面壳、主数据区、按需详情区组织。页面拥有业务状态，共享层拥有样式、可访问性、滚动和默认配置；页面不得复制共享组件源码、覆盖内部 DOM 或通过兼容别名绕过公共入口。
- Ant Design 是唯一通用组件体系：应用壳（`layouts/BasicLayout`：Ant `Layout.Sider` + `Menu` + 窄屏 `Drawer`）、页面根（`AppPage`：面包屑 + 一级标题 + 操作区 + 页签）、弹窗/抽屉表单（`ModalForm`/`DrawerForm`：Ant `Modal`/`Drawer` + `Form`）、分步表单（Ant `Steps` + `Form`）全部由 `components/ui` 基于 antd 实现；`@ant-design/pro-*` 已整体退役，静态门禁按依赖名拒绝重新引入。导航树 `routes/menuRoutes`（`MenuEntry`：`path`/`label(t)`/`icon`/`hideInMenu`/`children`）是菜单、路由高亮、面包屑与页面默认标题的唯一来源，`label` 以 `(t: TFunction) => t("…")` 静态给出文案键，不走动态 key 登记；布局按 `matchMenuChain` 算出当前导航链并通过 `RouteCrumbsContext` 下发。ECharts、Monaco、dnd-kit（`@dnd-kit/react` 系列）、react-markdown、cronstrue 等仅承担专项能力；禁止引入第二套 Button、Form、Card、Modal、Tooltip、Table 或布局体系。
- 依赖新增或升级前核对真实调用方、React/Ant peer 契约、按需加载、包体、浏览器支持和构建结果。能由现有框架稳定完成的能力不再引库；禁止复制依赖源码、劫持 console 或关闭检查来隐藏兼容问题。
- 修改顺序固定为：确认业务契约与调用链，选择或完善共享机制，再迁移页面，最后增加能长期识别同类回归的门禁与真实测试。禁止先在单页堆样式再反向总结规则。
- 落实边界：import 与组件入口边界由静态门禁强制；目录职责划分、命名语义与组件晋升（两个真实页面复用）由人工评审判断，不按文件行数设静态门禁。

- **共享层命名用通用词，尺寸常量用整齐的数**：共享组件、Hook、工具函数和它们的 props 用描述“它是什么/做什么”的通用词（`compareText`/`sortByText`、`InlineListItem.text`、`columnWidth.long`），不把某一次调用场景的词（如 label/tag/cell）带进通用名，只有该词本身就是标准语义时才保留（`aria-label` 一类的可访问名称仍叫 `label`）。手写的布局/尺寸常量（列宽、图节点尺寸、图层间距、容器上限）取 20 的倍数（`180/100/420`），间距、圆角、控件高度取 4 的倍数（`--ds-space-*`、`--ds-radius-*`、`--ds-control-*`，只有 2px 细线间距例外），结构宽度（`--ds-layout-*`）取 20 的倍数，不出现 `5/6/88/136/184` 这类零散数；嵌套圆角按同心计算（内圆角 = 外圆角 − 内边距）。静态门禁校验 token 源。

## FRONTEND-THEME：唯一主题与设计标度

- **语义色随底色适配（反色表面）**：显式设置 `data-surface="inverse"` 的黑/白反色容器是“反色表面”；分段项使用品牌弱底，不属于反色表面，上面的语义色必须换成另一套——`tokens.css` 为 link/info/success/warning/error 各发布 `*-on-inverse`（亮色主题取暗色主题的同名值，反之亦然），并在 `[data-surface="inverse"]` 里把 `--ds-color-*` 改绑到 `*-on-inverse`；语义色变量可继承，业务里 `var(--ds-color-success)` 的图标/文字进了反色表面自动换色，不需要知道自己在哪个底上；其他需要反色的容器加 `data-surface="inverse"`。黑底上的深绿、白底上的浅绿都是错的（运行时门禁：所有可见图标与所在底色 ≥ 3:1，契约夹具在亮暗两套主题下精确断言选中项语义图标取到 `*-on-inverse` 值；Ant 下拉后缀与表头图标的基色同样收到不低于 3:1）。
- **正文纯黑/纯白，次级文字用真次级灰**：`--ds-color-text` 在亮暗两套里仍是 #000/#fff；`--ds-color-text-secondary`（表头、字段标签、说明、操作符）是真实次级灰——标签与值必须一眼可分，不能把标签渲染成和正文同色。更深的灰度只表达“未选中/禁用”——未选中的菜单项、页签、分段项、开关关态轨道用 `--ds-color-text-tertiary`/`--ds-color-text-disabled`，悬停回到纯色；**选中态全站一套 accent 语言**：侧栏菜单、分段项、分页选中项统一 `primarySurface` 弱底 + `primaryText` 文字；横向页签用 line 原生选中（主色文字 + 主色下划线），同属主色 accent 但不用弱底。
- 设计标度双源同构：`src/design/tokens.css` 是颜色唯一来源，亮色定义在 `:root`、暗色经 `:root[data-theme="dark"]` 覆盖同名变量并声明 `color-scheme`；`src/design/tokens.ts` 只保留尺寸、字体、布局与两种模式共用的图表数据色板。`src/config/theme.ts` 在运行时从 CSS 变量派生 Ant 颜色，应用壳与页面容器只消费这些变量。所有 `--ds-*` 引用必须有同源定义且已发布变量必须有真实使用方；业务 CSS、TSX、图表不得另建调色板或标度。
- **全站品牌主题只有一个可编辑种子**：只改 `src/design/tokens.css` 的 `--ds-color-brand`；`primary/hover/active/surface/border/focus` 的亮暗两套档位从品牌种子自动派生，实心按钮前景保持白色，`src/config/theme.ts` 再把它们映射到按钮、选择态、输入焦点、分页、日期、开关、步骤、滑块、树和表格选中行。黑白混合锚点只负责让任意品牌种子在两种主题下得到可读的深/浅档，不是第二份品牌配置。业务层不得覆盖派生档位；状态色和图表分类色保持独立，避免“换品牌”把成功、警告、错误的语义一起改掉。静态单测强制品牌种子只定义一次、暗色主题不得另存第二份种子、所有交互主色档位必须沿派生链取值。
- 字号采用六档职责制：12（辅助元数据、时间戳与字段说明，Ant `fontSizeSM`）｜14（正文、表格内容、表单控件，Ant `fontSize`）｜16（区块标题与大号正文，H3）｜20（页面内大标题，H2）｜24（唯一页面一级标题，H1，仅 AppPage）｜28（指标大数字）。同一语义角色跨页面同档，正文不得低于 14px，不以局部缩字号修补布局；普通控件高度统一 32px。字体、间距、圆角使用唯一 token，不新增私有标度。业务字体族直接引用同源 token；拥挤时优先调整列宽、滚动与图标紧凑态。
- 中性 token 表达画布、表面、边界与文字层级；蓝色只用于链接、焦点、信息和交互选中；成功、警告、错误色只表达真实状态。普通图表系列只用数据色板，同一图表不重复颜色。
- 普通卡片不用装饰阴影；Modal、Drawer、Popover、Dropdown 使用统一抬升层。hover、focus、active、loading 不得改变控件或相邻内容几何位置。
- 控件尺寸统一三档：小 24、中 32、大 40（`designTokens.control`，由 Ant 主题 `controlHeight/SM/LG` 映射），同一操作区与工具栏内只用一档；禁止用 CSS 或内联样式覆盖 Ant 控件的高度与圆角，窄屏需要整项换行时才允许按内容增高且限定在 compact 断点内。按钮宽度由内容与统一间距决定，不设固定宽度。
- 间距、字号、圆角、控件高度和结构宽度来自 token；Table 列宽、图表画布、编辑器视口等领域尺寸可本地声明，但必须有明确滚动所有者或响应式验证。测量值、百分比和图表坐标属于运行时契约，不用于装饰布局。
- 颜色百分之百纳入双主题体系：业务 CSS、TSX、图表与 Ant 组件属性不得出现任何硬编码颜色值或 Ant 预设色板名（red/cyan/geekblue 等），静态门禁拒绝十六进制、命名色、颜色函数裸值与预设色板字符串，运行时读取统一经 `readCssColorToken`；阴影同样以 `--ds-shadow-*` 双主题变量发布，Modal、Drawer、Popover、Dropdown 抬升与焦点环随主题切换。唯一例外是 `src/design/tokens.css` 的 token 源与 `tokens.ts` 中两种模式共用的图表数据色板。`src/config/theme.ts` 映射 Ant 组件 token 时，带 dark 变体的组件（如 Menu 的 `itemColor`/`darkItemColor`）必须亮暗成对映射，门禁强制——漏配 dark 变体会让收起态侧栏等 dark 场景回退到 Ant 内置默认色，逃逸出切换体系。
- 中性色板保持亮色画布 `#f6f6f4`、表面 `#ffffff`、文字 `#000000`，暗色画布 `#080808`、表面 `#111111`、文字 `#ffffff`；品牌色默认种子为 Ant Design 蓝色 `#1677ff`，暗色将相同种子混入当前表面得到更沉稳的蓝色；不把主操作换成纯白。中性灰只保留承担真实层级的少数档位，全部无色偏；链接和信息色、成功/警告/错误状态色、图表分类色各自保持稳定语义，不从品牌色派生。**文字只有一套普通前景色，品牌实色表面另有自动派生的 `primary-foreground`**：普通内容继续使用 `text`/`text-secondary`/`text-tertiary`，主按钮使用 `primary + primary-foreground`（默认亮色底取蓝色种子 94% 与黑色混合，使 14px 白字达到 4.5:1），分段选择使用 `primary-surface` 弱底和 `primary-text` 文字（暗色弱底上的品牌文字单独提亮，不改变按钮底色），页签用 line 原生的主色文字与下划线，保留当前主题语义图标色；Ant 主题在算法之后经 `createPreserveSemanticColors` 把品牌色与状态色还原为 token。新增颜色 token 前必须先证明现有档位无法表达该语义。
- 层级立体感的全局机制：表面三档各司其职——`surface`（基础表面）、`surface-muted`（容器与内嵌底）、`surface-elevated`（浮起层，暗色下必须比 surface 更亮）；一切“浮起”的元素（Popover、Dropdown、弹出菜单经 `colorBgElevated`）一律用 elevated 档加双层 `--ds-shadow-choice` 阴影（Segmented 选中药丸是弱底嵌件不是浮层，走品牌弱底不加阴影），禁止用基础表面或更深的颜色制造“浮起”导致凹陷观感。
- 中性灰阶克制：悬停用 `surface-subtle`、容器与内嵌底用 `surface-muted`、浮起用 `surface-elevated`；Ant 的 `colorFill*`、`controlItemBg*`、`colorBgTextHover` 等填充与悬停 token 统一映射到这三档，不允许 Ant 算法从主色派生带色偏的灰；层级优先用表面与边框表达，不用叠加灰阶制造层次。
- 亮暗双主题：偏好三态 `system`/`light`/`dark`，默认跟随系统（`prefers-color-scheme` 实时响应），持久化在主题存储键（生成参数 `ThemeStorageKey`，默认 `<slug>-theme`）并跨标签页同步；切换只改根节点 `data-theme`/`color-scheme`/主题 class，CSS 变量由静态双主题块自动生效，无 JS 重装。Ant 主题经 `buildThemeConfig(mode)` 在暗色启用 `darkAlgorithm` 并运行时读取 CSS 变量。唯一切换入口是应用壳的 `ThemeToggle`（在生效亮暗间直接切换）。TSX 颜色引用 `var(--ds-color-*)` 随模式自动切换；ECharts 画布无法解析 CSS 变量，语义色必须经共享 `useChartColors()` 读取当前 CSS 变量字面量并随生效主题 memo。关键前景与表面组合在两种主题下的对比度由专项单测保证。
- 禁止十六进制、CSS 命名色、CSS system color 及颜色函数裸值；设计 token 源外不得以任意名称定义私有颜色、间距、字号、圆角等设计变量，进度、测量等只表达运行时状态的变量可以保留。禁止 Ant 私有变量、`!important`、业务覆盖 `.ant-*`、关闭 hashed 样式、根节点隐藏溢出和 hover 位移；`transparent` 表示无色、`currentColor` 表示继承当前前景色，可直接使用。`border`/`border-image`、`mask-border`、`background`、`boxShadow`、`column-rule`、文本装饰及滤镜等可携色复合值中的颜色同样必须来自语义 token，不得把裸颜色藏在渐变、阴影或边框字符串中；标准属性的 `-webkit-` 等浏览器前缀不构成例外。Ant `Space.size`、`Row.gutter`、`Flex.gap` 必须使用统一间距，静态 spread 中的间距也遵循相同规则。

## FRONTEND-STYLE：唯一样式方案与命名设计

- 样式唯一方案是"同目录普通 CSS 文件 + `--ds-*` 设计变量 + 语义类名"：组件样式文件与实现放在同一目录并由组件自身导入；禁止引入 `antd-style`、styled-components、CSS Modules、Tailwind、Less 新文件等第二套样式机制。新增样式优先写成 CSS 类；TS/TSX 内联 `style` 与 Ant 组件样式 props 只允许引用 `designTokens` 同源 token 或运行时动态值（测量值、坐标、由数据计算的尺寸），禁止裸值——类名承载结构与复用，内联只承载 token 映射。
- 共享层（`components/`、`components/ui/`、`layouts/`）类名统一使用 `ds-` 前缀加 BEM 结构 `ds-block__element--modifier`；`ds-` 前缀为共享层保留，页面样式不得占用，避免全局冲突与归属歧义。页面样式类名使用页面语义的 kebab-case 块名（如 `item-pool-details__header-list`、`kpi-cards`），同页私有组件就近放在 `pages/<Page>/components` 并以页面语义命名，不使用无语义的 `wrapper`/`container`/`box` 块名。
- CSS 变量命名统一为 `--ds-<类别>-<名称>`（类别限 color、font、space、radius、motion、layout），只在 `src/design/tokens.css` 发布定义；`src/design/tokens.ts` 负责同源尺寸与字体的 TS 入口；数值梯级变量以像素值结尾（如 `--ds-space-16`），新增变量必须有同源定义和真实使用方。业务代码不得定义 `--ds-` 前缀以外的设计变量，也不得引用未发布的 token。
- CSS 媒体查询断点只使用 480/640/768 三档，与 `designTokens.breakpoint` 的 compact/narrow/mobile 同源；需要 JS 行为分支时必须引用同一 token 数值，不得另写断点常量。样式文件统一为普通 CSS（原生嵌套），不引入 Less 等预处理器。

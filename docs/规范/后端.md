# 服务规范

项目不维护内容数据库或身份数据库模型。官方组件负责文件同步、上传和编辑；Caddy 和可选 authentik 负责入口认证。统一面板仅维护服务端 API v3 适配，不实现密码或会话。优先使用公开配置，不修改依赖源码或注入替代协议。

默认 Studio 只监听本机。容器部署不能直接映射未保护的 Studio 端口；反向代理须覆盖页面、模块、上传、资源与 WebSocket。凭据经运行环境传入，不写进可被 Vite 提供的配置模块。

MDX 是可信作者的可执行构建输入。构建运行在隔离环境，不能携带生产运行密钥。附件发布是文件复制，不具备数据库时代的私有附件、引用保护或审计能力，不得在文档中沿用旧承诺。

读者构建与编辑进程独立。发布失败不能破坏已有产物，生产部署使用新制品替换；保存文件不等于发布，也不等于已提交 Git。需要自动化时配置现有 CI/CD，不重新实现发布后台。

账号 API 只操作 dsdocs 路径的 internal 用户，字段使用允许清单，不接受角色、路径、用户组等任意写入。不能停用当前登录账号；启用前确保编辑组授权成功。令牌只留服务端，管理端口仅私网可见，身份头只可信认证代理产生。省略账号模块时不要求身份环境变量、数据库或网络连接。身份服务故障不能自动降级为匿名访问。

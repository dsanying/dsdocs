# 发布准备

项目通过 GitHub 源码仓库分发；正式版本可使用签名标签和 GitHub Release 记录变更、兼容范围、部署步骤及已知限制。需要容器分发时另构建 reader/management 两个目标并发布对应镜像摘要。源码提交不等于正式发布。

发布前执行 pnpm check、pnpm test:browser、pnpm audit:all，复核账号权限、子路径、草稿隔离、恢复备份及镜像运行。第三方许可证由依赖锁文件收集，项目 MIT 不替代第三方许可义务。

当前任务只准备源码、规范及本地验证，不创建正式标签、Release、推送镜像或部署集群。未完成的验收不得写成已通过。

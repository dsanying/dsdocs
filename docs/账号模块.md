# 本地账号

默认开启本地账号，不依赖外部身份服务。首次启动创建 admin/admin，首次登录只允许修改默认用户名和密码。新密码 8–128 字符，用户名 3–64 位字母、数字、点、下划线或连字符。密码哈希保存，不能查看原密码；超级管理员的“修改密码”表示重置。

超级管理员可以管理普通管理员，不能删除或降级自身。普通管理员只能查看自己，修改自己的账号需要当前密码。二者编辑文档的权限相同。账号修改后会话撤销，需要重新登录。

DSDOCS_AUTH=none 显式禁用账号模块，适用于已有网关认证的入口或仅本机使用；不启用时不创建账号数据库。生产入口应使用 HTTPS。配置、备份、日志和截图不得暴露真实凭据。

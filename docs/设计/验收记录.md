# 验收记录

日期：2026-10-16。当前架构为原生 Fumadocs 静态读者端与官方 Studio，旧数据库后台的接口数量和覆盖率不适用于本版本。

已执行类型检查、附件复制回归、静态构建与第三方许可收集。附件复制检查删除后重建的清理行为，并拒绝文件及根目录符号链接。

安装的 Google Chrome 155.0.8059.80 中执行官方 Studio 的七组界面流程：工作区加载、源码保存与刷新恢复、可视化保存、创建目录与页面、删除取消与确认、原生图片上传与引用保存、移除图片引用后的文件保存。浏览器未出现 pageerror。测试使用独立配置和临时内容目录，不改真实文档。

读者端在 Chrome 与 Firefox 中检查原生组件、公式、静态搜索、中英文关联切换、语言偏好和窄屏布局，没有后台 API 请求。另将 Studio 实际保存的 MDX 和上传图片放入仓库外独立读者项目，离线安装并构建，验证静态图片可加载。

本地构建 reader 与 studio 镜像。Caddy 拒绝匿名页面、上传、附件和模块请求；匿名 WebSocket 升级返回 401。认证后的 Chrome 能连接工作区；停止 Studio 容器后，静态读者页面与搜索仍可使用。非 root 容器直接执行官方 CLI，不在启动时重新安装依赖。

上游边界：Studio 仍为实验版本；没有完整目录重命名、附件管理、账号管理或成对翻译面板；保存不等于 Git 提交或发布。生产入口、并发协作、大规模搜索性能、全部 MDX 扩展及每行上游代码未在本轮声明已验证。Next.js 的 CSS 优化器对上游 highlight 伪元素仍有两条提示，没有隐藏或删除样式。

本轮不创建 Release 或标签，不上传镜像，不部署集群。原始日志、截图和容器验证报告存放在仓库外。

## 可选统一面板与身份模块

同日增加 `apps/manage`。官方 Studio 保持独立；统一面板仅组合官方 Editor UI/Core 和必要的账号表单。authentik 2026.8.4 的原生中文用户管理页与中文登录已在实际 Chrome 中确认，默认品牌通过原生配置设为 zh-Hans。文档编辑器按用户确认保留官方英文界面。

`pnpm check` 包括四组账号适配测试，核对外部账号范围拒绝、创建失败不授权、分页遍历及上限、启用前组授权、匿名请求、来源与格式检查、超限请求。统一面板 Chrome 测试覆盖无账号运行、文件保存刷新、切换账号页时继续保存、亮暗主题、移动目录和服务端代码访问拒绝；模拟列表响应另覆盖读取失败重试、分页、中文匹配和空结果。模拟列表不冒充真实身份服务测试。

隔离 authentik 实例上的九组真实 Chrome 流程已通过：匿名与伪造身份头拒绝、无编辑组用户拒绝、阻止停用自身、取消表单丢弃草稿、创建及刷新后搜索、新账号登录、密码重置及启停、跨范围与跨站写入拒绝、停用后已有会话和编辑连接失效。浏览器未产生 pageerror。账号密码和会话均在仓库外保存，不输出到截图或日志。

另行停止身份服务，后台返回 502，读者端继续返回 200。移出编辑组后，已有会话后续请求在本地约 26 秒后被拒绝；停用后的既有请求与编辑连接在本地约 30 秒内失效。这些只是当前本地实例的观测，不是撤权时限承诺。共享身份实例、生产 HTTPS 与多机缓存策略仍需在目标环境验收。

读者端双浏览器、原版 Studio 七组流程、Basic 入口与独立读者容器测试再次通过。management 镜像以非 root 身份运行，包含实际生产依赖许可。Vite 客户端打包保留上游 use-client 指令及包体积提示，没有通过隐藏警告或修改依赖获得通过。

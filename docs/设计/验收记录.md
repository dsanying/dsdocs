# 发布准备验收记录

日期：2026-10-16。本记录只描述 dsdocs 当前支持范围，详细日志与审核证据保存在仓库之外。

管理端的验收覆盖真实页面、接口与持久化结果。第三方组件自身的测试不能代替应用流程验证。

完整验证入口为 `pnpm check`，发布准备入口为 `pnpm release:prepare`。前者包含三套应用的静态检查、测试、构建及两种浏览器的真实业务流程；后者增加生产依赖审计、容器构建、账号烟测和下载产物生成。

管理端集成验收覆盖源码即时保存、未完成语法草稿、可视化输入、发布拒绝、历史恢复、删除、翻译关联、附件、账号权限切换和密码重置。匿名读取、草稿隔离、私有预览、会话撤销、并发、幂等和路由冲突同时由服务层测试验证。

文件读者端使用独立内容目录和锁文件，能够在没有后台和数据库的环境中构建并运行。浏览器验证检查静态搜索、原生组件、数学公式、翻译切换、语言偏好和窄屏，并拒绝任何后台 API 请求。

静态搜索采用 Fumadocs 官方 FlexSearch 客户端与原生搜索组件。原默认搜索依赖的 Unicode 分词在本轮 Firefox 中把部分中文短词标为非单词，已用实际浏览器反例确认，未修改 Fumadocs 上游源码。

已知边界：官方可视化编辑器仍处实验阶段，部分编辑控件文案为英文；管理端包含组件库产生的较大分块，编辑器已按需加载。Next.js 的 CSS 优化器仍对上游 `::highlight(fd-search)` 给出两条提示，未隐藏提示或删除样式。

本轮不创建正式版本标签、GitHub Release，不上传容器，不部署到集群。静态导出不含私有数据，也不能替代数据库备份。

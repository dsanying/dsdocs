# 能力与验收

| 能力                                     | 来源和边界                                                                                    |
| ---------------------------------------- | --------------------------------------------------------------------------------------------- |
| 文件目录、创建、删除、排序               | 官方 Studio/Editor 文件树与 meta.json；无目录重命名界面，名称修改通过文件系统及 meta.json     |
| 可视化与源码编辑、自动保存、外部变更合并 | 官方 Studio；上游实验阶段                                                                     |
| 上传图片                                 | 官方上传服务，PNG/JPEG/WebP，5 MiB；不提供附件管理中心                                        |
| 协作                                     | 官方可选能力，默认未开启，不承诺本项目已验收                                                  |
| 搜索、语言菜单、目录、主题               | 原生 Fumadocs 组件与静态内容源                                                                |
| 中英文关联                               | zh/en 相同相对路径，缺译跳到目标语言入口；无并排翻译管理                                      |
| 账号与权限                               | 本机无需账号；可选 authentik 原生中文账号管理，统一面板提供创建、启停、重置密码；组内同等权限 |
| 历史与发布                               | Git 管理历史；构建后部署静态产物，没有数据库草稿与审核流                                      |
| 独立运行                                 | 读者端只依赖 MDX 文件与静态产物，编辑端宕机不影响已发布站点                                   |
| 子路径                                   | 读者端 /docs；Studio 独立私有入口，不能承诺 /docs/admin                                       |

附件删除通过文件系统或 Git 完成；删除图片引用只修改正文，不自动清理磁盘文件。构建会公开 assets 中所有文件。没有自动 Git 提交、自动部署、读者实时推送或阅读人数统计。

检查结果记录在 [验收记录](验收记录.md)，不沿用旧数据库后台的测试数量或覆盖率。

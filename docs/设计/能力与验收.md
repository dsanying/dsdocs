# 能力与验收

| 模块 | 必须验证 |
| --- | --- |
| 账号 | 首次设置前阻止管理、默认凭据失效、管理员仅可看自己、超管管理普通账号、超管删除拒绝、改密后会话失效 |
| 目录 | 新建、重命名、父目录、循环拒绝、非空删除拒绝、读者目录更新 |
| 文档 | 创建、翻译关联、元数据、自动草稿保存、刷新重读、源码切换、提示框/表格/代码语义保留 |
| 发布 | 保存不公开、发布即时可见、非法内容拒绝且旧版保留、路径冲突、撤下、历史恢复到草稿 |
| 附件 | 类型与大小、上传、草稿预览、未发布不可读、发布可读、被引用拒绝删除、移除引用后删除 |
| 读者 | /docs 子路径、搜索更新与中英隔离、语言对应页切换、亮暗主题、宽窄屏、管理停止后仍可读 |
| 工程 | 类型、构建、规范链接、接口映射、密钥扫描、依赖审计及真实浏览器记录 |

新架构不复用旧 Studio/authentik 测试结论。覆盖率必须实际测量，不宣称前端操作覆盖每一行。尚未执行、失败和通过分别记录。

# 能力与验收

## 当前范围

| 能力       | 行为边界                                                                    | 验收入口                                |
| ---------- | --------------------------------------------------------------------------- | --------------------------------------- |
| 本地账号   | 初始化、登录、退出、新增、禁用、恢复和重置密码；所有有效账号权限相同        | 真实管理页面与数据库测试                |
| 会话与权限 | Origin、CSRF、当前账号状态、会话到期与撤销；保留至少一个有效管理账号        | 拒绝路径、迁移及真实 PATCH 请求         |
| 文档       | 标题、摘要、路径、嵌套目录、排序、中英文关联、草稿与发布快照                | 原文保存、双语跳转和匿名隔离            |
| MDX 编辑   | 官方可视化编辑、源码模式、未完成语法草稿、即时保存、私有预览                | 可视化输入、快速保存和非法发布拒绝      |
| 历史与删除 | 不可变版本、历史恢复为新草稿、下线和软删除                                  | 恢复与删除后的公开状态                  |
| 附件       | PNG/JPEG/WebP/PDF，单个不超过 5 MiB；草稿私有，发布引用后公开，历史引用保护 | 上传、图片加载、匿名拒绝和删除          |
| 文件部署   | 已发布 MDX 和引用附件导出，独立文件源构建静态站点                           | 无数据库构建、静态服务、零后台 API 请求 |
| 搜索与语言 | 公开快照搜索、官方静态搜索客户端、关联翻译、浏览器语言初选及本地偏好        | Chromium 与 Firefox 实际跳转            |
| 管理界面   | 通用命名、中英文、亮暗主题、窄屏导航、分页表格、写操作反馈                  | 全部实际菜单、表格与账号操作            |

管理端采用通用文档管理模型和 Ant Design 组件。文档前台和编辑器保留 Fumadocs 原生组件。

## 明确不包含

当前没有自动 Git 提交或自动部署、数据库归档导入、协同编辑、服务端自动保存、命名版本、目录独立实体和拖动排序。SSO、空间权限及读者分组也不属于统一后台权限模型。

内容服务使用单实例 SQLite，不支持共享数据库文件上的多实例、对象存储或持久任务队列。文件读者端没有这些运行依赖，适合独立静态部署。

Mermaid、OpenAPI、TypeTable、include 和自定义执行模块的读者端接入不在当前支持集合。不能因为上游编辑器能显示某种组件，就将其记为 dsdocs 已完整支持。扩展前需要补齐存储、校验、编辑、渲染、导出和真实交互的整条链路。

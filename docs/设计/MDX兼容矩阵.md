# MDX 兼容矩阵

MDX 源码原样持久化。元数据表单与正文分离；正文可包含 YAML frontmatter，出现 title 时必须与文档标题一致。YAML 重复键和别名展开失败必须报错。

| 语法                                                        | 首版处理                                | 验证方式                                                                        |
| ----------------------------------------------------------- | --------------------------------------- | ------------------------------------------------------------------------------- |
| 标题、段落、强调、引用、有序/无序列表、链接、图片、行内代码 | 官方编译器                              | 源码、TOC、真实页面                                                             |
| GFM 表格、任务列表、删除线、脚注                            | 官方插件                                | 组合示例编译与浏览器                                                            |
| 代码围栏、语言、标题、行高亮                                | Fumadocs 编译器及原生代码组件           | 多行复制、滚动、语法高亮、页签                                                  |
| 行内/块级数学                                               | remark-math + rehype-katex，trust=false | 服务端编译与实际公式排版                                                        |
| Callout、Card、Cards                                        | 原生组件                                | 注册表、校验、实际渲染同源                                                      |
| Tabs、Tab、Steps、Step                                      | 原生组件                                | 嵌套、属性和交互                                                                |
| Accordions、Accordion、Files、Folder、File                  | 原生组件                                | 展开/关闭、嵌套及主题                                                           |
| 组件属性                                                    | 按注册属性校验类型                      | 接受字符串、布尔、数值及 Tabs 字符串数组，拒绝对象、计算属性、spread 和函数调用 |
| 标量和标量数组正文表达式、MDX 注释和 fragment               | 保留                                    | 解析与编译，拒绝对象正文                                                        |
| 有限 HTML 元素                                              | 明确元素和属性白名单                    | 脚本、危险 URL、事件、CSS 注入负例                                              |
| 非字面量 JavaScript 表达式与模块 import/export              | 返回明确诊断，不执行                    | 保存草稿保真，发布与预览拒绝                                                    |
| 未注册组件或未知属性                                        | 返回名称及位置，不静默忽略              | 负例                                                                            |
| Mermaid、TypeTable、OpenAPI、include、任意 npm 组件         | 尚未接入                                | 不声称支持，不用普通文本伪装已渲染                                              |

扩展原生组件时，在 `registry.ts` 登记内容契约、在 `components.tsx` 绑定实现，并添加合法、非法、嵌套、复制/交互、亮暗主题及宽窄屏用例。不能只往白名单加名字就宣称适配完成。

数学插件顺序按 [Fumadocs 官方说明](https://www.fumadocs.dev/docs/markdown/math) 配置：rehype-katex 必须先于代码高亮运行，避免块级公式被误当作 math 代码语言；行内、块级公式及随仓全部双语示例都有编译回归。

可视化编辑使用官方编辑器。其源码解析有延迟，适配层单独读取实时文本缓冲区；语法未完成的草稿仍按原文保存，不能用“最近成功解析的文档”覆盖当前输入。编辑器提供的功能可能多于本项目读者端支持集合，以本表及后台校验结果为准。

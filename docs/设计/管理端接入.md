# 管理端接入

管理端采用前端体系随包的真实共享实现：BasicLayout、SidebarFrame、AppPage、EntityEditPage、Table、DrawerForm、ResponsiveTabs、ResponsiveActions、反馈入口、双主题和中英文目录。项目独立维护这些源码及门禁，不依赖开发者机器上的技能路径。

## 页面职责

导航树是路径、菜单、面包屑及默认页面标题的唯一来源。管理入口使用 `/`、`/folders`、`/assets`、`/settings`、`/files`、`/accounts`。登录表单也由 React、Ant Design 和相同主题构成；服务端继续强制认证、首次设置和角色校验。

账号和目录是配置条目，列表完整展示普通属性，右侧抽屉编辑。附件列表展示文件名和大小，上传和受引用保护的删除属于资源操作，不额外创建无信息增量的详情页。网站设置是单例编辑对象，通过 EntityEditPage 提供脏状态、取消和保存。

文档是写作工作台，保留已确定的自动保存草稿、手动发布流程。它采用 AppPage 和共享导航、分区滚动及表单；正文复用 MDXEditor 的原生富文本、源码、代码和指令插件。不会为套用普通 CRUD 流程而添加第二份保存按钮，也不会将自动保存变为自动发布。编辑状态由 useDocumentEditor 持有，切换管理页时工作台不卸载。

页面入口组合本页展示组件；列定义在 columns.tsx，复杂写作和设置状态在本页 Hook，资源请求集中在 services。共享组件不引入账号或业务数据依赖，应用壳的自定义名称经公开属性注入。

## 布局与反馈

应用导航、文档树、编辑正文分别拥有滚动区域。账号、主题和语言控件固定在主侧栏底部。窄屏主导航进入抽屉，文档列表独立展开；不通过缩小字号或隐藏操作修补布局。源代码使用 CodeMirror 自有滚层，切换源码与富文本不更换内容来源。

读取失败原位展示并允许重试；写操作使用唯一共享通知入口。草稿保存失败是持续状态，保留未保存内容，允许重试或确认丢弃后重新加载。请求适配器保留 HTTP 状态，过滤服务端错误正文；DSdocs 的原始 JSON 不套入共享请求工具的响应信封。

## 接入与验证差异

基线修订为 2026-10-17-standalone。DSdocs 只做项目内适配：站点名称属性、业务路由和接口、Markdown 专业组件、格式化及中性注释。门禁路径按 apps/manage 的嵌套目录接线；滚动选择器校验忽略格式化产生的等价空白，仍检查完整集合。没有修改全局技能、伪造复刻摘要或外部软链接。

共享组件契约测试和实际业务浏览器测试分别运行。共享表单同时在生产包与开发 StrictMode 运行时验证，开发夹具检查真实的两次 effect 挂载，并覆盖文本、只读值、排序与布尔值的回填、修改和取消重开。静态检查与构建在本地和 CI 执行；浏览器验收在本地执行，两套浏览器均不配置失败重试。完整入口是根目录 pnpm check；前端子入口按 manifest 执行 static、build、ui，增量入口只用于开发过程，不能替代最终完整验收。

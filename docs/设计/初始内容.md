# 初始内容

采用项目教程和格式示例组合。使用者可以直接在后台阅读和修改自己的文档，既能了解 DSdocs，也能验证编辑、保存、发布和中英文切换。结构参考文档项目的常见入门模板，正文为本项目原创，不复制其他项目教程。

## 内容组织

`apps/manage/starter/manifest.json` 登记目录、页面和附件。中英文正文分别放在 zh/en 下的 Markdown 文件中，不把数据库或固定附件 ID 写入源码。四个主题分别为快速开始、编写与发布、Markdown 格式示例、部署与备份，共八篇关联页面。

格式示例覆盖当前契约中的常用内容，未支持的扩展明确列出，不将其他项目支持的功能当作本项目能力。图片和文本附件随初始包分发，运行时生成随机附件 ID，无外部图片服务依赖。workflow.svg 是示意图的可编辑源文件，实际导入 PNG。

## 初始化规则

管理端只对首次创建的内容数据库自动载入教程，默认 `DSDOCS_STARTER=guide`，`none` 可关闭。已有数据库即使为空也不自动补齐，不覆盖作者改动，不恢复已删除内容。初始化正文先经过发布语法校验，文档、关联翻译、目录、附件元数据和发布历史在同一事务中写入；失败清理本次写入的附件。

编辑初始 Markdown 模板只影响之后新建的站点。已经导入数据库的页面仍通过后台编辑和发布。

已有空站点可由拥有服务器文件权限的维护者执行 `pnpm content:init` 显式载入；存在文档、目录或附件时拒绝执行，命令不提供强制覆盖参数。当前本机预览的旧通用示例另行备份后替换，不借此改变正常升级行为。

语言根路径优先展示 getting-started；不存在该路径时保留原来的首篇文档行为。读者仍从数据库读取已发布快照，初始化后无需按正文重新构建。

## 验证

`starter-regression` 检查八篇快照、成对翻译、站内链接、附件内容、关闭开关、已有内容保护、删除后不恢复，以及失败回滚。`pnpm test:starter:browser` 在临时新站中检查默认首页、中英文切换、完整格式渲染、图片及下载，并从后台真实编辑与发布 Markdown 示例。

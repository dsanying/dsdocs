# 组件选型

| 模块 | 组件 | 所有权 |
| --- | --- | --- |
| 管理布局、主题、表格、表单、通知 | Ant Design + 本仓 src/components/ui、design、config、utils | 从个人前端体系生成基线后项目适配；不声明逐像素复刻 |
| 可视化正文 | MDXEditor 官方插件 | 保留编辑内核和源码切换 |
| 读者布局、目录、导航、提示框、代码外壳、搜索弹层 | Fumadocs UI/Core | 不维护上游分叉 |
| 正文解析 | react-markdown、remark-gfm、remark-directive | 仅配置限定语法及组件映射 |
| 高亮 | Shiki | 围栏代码作为文本，不运行代码 |
| 账号 | Better Auth，SQLite | DSdocs 封装简单角色、首次设置及账号 API |
| 内容 | node:sqlite | DSdocs 数据结构、草稿冲突与发布事务 |

管理端共享源码保留完整组件契约，首版页面仅使用必要组件；无业务图表、AI、协作或任意 MDX 功能。基线在本仓适配了账号菜单导出、翻译缺项、拖动依赖版本和应用上下文，不修改全局技能包。
